# 어울림 PC판

> “자리에서 시작되는 우리 반의 새로운 이야기”

교사를 위한 Windows 자리 배치 프로그램입니다. 인터넷 없이 동작하고, 학생 명단과 배치 기록은 **선생님 PC 안에만** 저장됩니다.

## 내려받기

[**최신 버전 내려받기 (Releases)**](https://github.com/pobydev/eoullim-pc/releases/latest)

| 파일 | 이럴 때 |
|---|---|
| `Eoullim-Setup-<버전>.exe` | 내 PC에 설치해서 쓸 때. 새 버전이 나오면 자동으로 업데이트돼요. |
| `Eoullim-USB-<버전>.exe` | 설치 없이 USB에 넣어 쓸 때. 자료는 실행 파일 옆 `어울림-자료` 폴더에 저장돼요. 재부팅하면 초기화되는 학교 PC나 여러 PC를 오갈 때 좋아요. |

처음 실행할 때 Windows가 “PC 보호” 창을 띄우면 **추가 정보 → 실행**을 눌러 주세요. 개인이 만든 프로그램이라 코드 서명이 없어서 나오는 안내예요.

## 할 수 있는 일

- 기본형·짝꿍형·모둠형 교실, 최대 64석, 통로 만들기
- 지정구역(앞자리 등), 고정석, 남녀 짝·동성 짝 조건
- 큰 발표 화면과 자리 공개 애니메이션, 3·2·1 카운트다운
- 엑셀 양식으로 명단 올리기, 배치 기록 저장
- A4 인쇄와 PDF 저장 (교사 시점·학생 시점)
- 백업 파일로 다른 PC에 옮기기

## 웹 어울림을 쓰셨다면

웹 어울림(eoullim.vercel.app)은 2027년 2월 26일에 종료됩니다. 웹에서 **PC판으로 옮길 파일 내려받기**를 누른 뒤, PC판 **앱 설정 → 백업 불러오기 → 학급으로 추가**를 고르면 명단과 저장한 배치가 그대로 옮겨져요.
